1. **脱敏规则**：姓名→首字母、薪资→隐藏、公司→可选、手机→掩码、邮箱→掩码

## Resolution

已确认。F10 决议：

**脱敏规则（固定，用户勾选开关）：**
- 姓名 → 首字母（王→王**），默认显示
- 电话 → 中间4位掩码（138****1234），默认脱敏
- 邮箱 → 掩码（w***@xxx.com），默认脱敏
- 薪资 → 隐藏，默认脱敏
- 公司名 → 原样/隐藏可选，默认显示
- GitHub → 原样/隐藏可选，默认显示

**操作方式：** Web 预览时用户勾选字段脱敏开关，实时看效果，满意后导出

**Python 脚本：** 正则匹配敏感字段、规则替换，用于 Node API server 导出时调用

**Skill 形式：** SKILL.md + Python 脚本 × 1
