# Résumé layout references

- [Harvard's bullet-point template](https://careerservices.fas.harvard.edu/resources/bullet-point-resume-template/) and [MIT's sample résumés](https://capd.mit.edu/resources/sample-resumes/) informed the straightforward reading order and distinct section headings.
- [Jake's Resume](https://www.overleaf.com/latex/templates/jakes-resume/syzfjbzwjncs) informed the compact hierarchy. The Compact preset reduces spacing before reducing type size.
- [ModernCV](https://ctan.org/pkg/moderncv?lang=en) and [Genki Ogaki's two-column example](https://www.overleaf.com/latex/templates/two-column-cv-template-with-moderncv/mqycjnmnswzz) informed the split contact header and date gutter. Body content stays in one reading order.

Editorial and Classic reserve serif type for display headings. The body, dates, and contact details use a system sans-serif stack. Dates and contact details request lining tabular figures. No example content or external font assets are included.
